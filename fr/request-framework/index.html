Demander un cadre
ou une langue

La couverture de CORAL s'étend grâce aux demandes de la communauté. Utilisez cette page pour soumettre une demande de nouveau cadre réglementaire, d'une nouvelle langue pour les manifestes, ou d'un nouveau langage de programmation. Toutes les demandes sont publiques et suivies sur GitHub.

Soumettre via GitHub

La méthode préférée. Ouvrez une Discussion dans la catégorie Demandes en utilisant le modèle ci-dessous. La communauté peut ainsi s'exprimer et les mainteneurs suivent les progrès de façon transparente.

Ouvrir une discussion

Soumettre par courriel

Vous préférez le courriel ? Envoyez votre demande à request@coral-oss.dev en utilisant le même modèle ci-dessous. Les demandes par courriel sont examinées et, avec votre permission, publiées sur GitHub.

request@coral-oss.dev

Vous souhaitez contribuer le manifeste vous-même ? Si vous êtes prêt à rédiger le manifeste YAML pour le cadre que vous demandez, votre demande sera priorisée. Consultez le Guide de contribution pour le format des manifestes.

Modèle 1

Cadre de conformité ou règlement

Utilisez ce modèle pour demander une nouvelle loi réglementaire (ex. HIPAA, LGPD) ou norme d'audit (ex. ISO 27001, FedRAMP). Copiez le bloc ci-dessous et remplissez vos informations.

demande-cadre.md Copier et remplir
Type de demande *
Cadre / Règlement
Nom du cadre *
ex. HIPAA, ISO 27001, FedRAMP, LGPD, NIS2
Utilisez le nom officiel et l'acronyme. Si le cadre a plusieurs versions, précisez laquelle (ex. PCI DSS v4.0).
Organisme de gouvernance *
ex. U.S. Department of Health & Human Services, ISO/IEC, AICPA
Juridiction *
ex. États-Unis (fédéral), Union européenne, Brésil, Australie
Cela devient le jeton JURIDICTION dans l'identifiant de référence — ex. HIPAA.US.§164.312a
URL de la source officielle *
ex. https://www.hhs.gov/hipaa/for-professionals/security/laws-regulations/index.html
Lien vers le texte juridique officiel ou le document de norme. Les URL gouvernementales et des organismes de normalisation sont préférées.
Langue parlée/écrite du texte officiel *
ex. Anglais uniquement / Français et anglais (bilingue) / Portugais
Si le texte officiel est dans une langue autre que l'anglais, indiquez-le. CORAL distingue la langue faisant autorité des traductions.
Pourquoi ce cadre est-il important pour votre projet ? *
Décrivez votre cas d'utilisation. Dans quel secteur travaillez-vous ? Quelle obligation ce cadre impose-t-il à votre code ?
Clauses ou contrôles concernés (facultatif mais utile)
ex. HIPAA §164.312(a)(1) — Contrôle d'accès ; §164.312(e)(1) — Sécurité de la transmission
Listez les clauses les plus pertinentes pour la conformité au niveau du code. Cela aide à prioriser les contrôles à implémenter en premier.
Pouvez-vous contribuer le manifeste ? (facultatif)
Oui / Non / Peut-être avec des indications
Les demandes avec un auteur volontaire sont priorisées. Si oui, un mainteneur vous contactera pour vous guider dans le format du manifeste.
Modèle 2

Langue parlée ou écrite

Utilisez ce modèle pour demander une nouvelle langue humaine pour les manifestes et rapports CORAL — par exemple l'espagnol, l'allemand, le portugais ou le japonais.

Note sur les langues faisant autorité. Lorsque le texte officiel d'une loi est dans une langue autre que l'anglais, CORAL la marque comme faisant autorité et signale toute autre langue comme traduction communautaire. L'exactitude des traductions non officielles relève de la responsabilité des contributeurs, et CORAL inclut une mention dans les rapports générés.

demande-langue.md Copier et remplir
Type de demande *
Langue parlée / écrite
Nom de la langue *
ex. Espagnol (castillan), Portugais brésilien, Allemand, Japonais
Utilisez le nom français suivi du code ISO 639-1 — ex. Espagnol (es), Portugais — Brésil (pt-BR).
Code ISO 639-1 / BCP 47 *
ex. es, pt-BR, de, ja
Cadres concernés *
ex. RGPD (texte officiel disponible dans cette langue), LGPD (langue principale)
Listez les cadres dont le texte officiel est disponible dans cette langue, ou pour lesquels vous souhaitez un manifeste traduit.
Cette langue fait-elle autorité pour un cadre ? *
ex. Oui — la LGPD fait autorité en portugais / Non — il s'agit d'une demande de traduction communautaire
Pouvez-vous contribuer la traduction ? (facultatif)
Oui / Non / Partielle
Les contributions de locuteurs natifs ou de professionnels juridiques sont particulièrement valorisées. Les PR de traduction sont soumises à la révision d'au moins un autre locuteur.
Contexte supplémentaire (facultatif)
Toute note pertinente sur les nuances juridiques, les variantes régionales ou les clauses spécifiques dont vous avez connaissance.
Modèle 3

Langage de programmation ou écosystème

Utilisez ce modèle pour demander le support d'un nouveau langage de programmation ou écosystème de paquets — par exemple Python (PyPI), Ruby (Gems) ou Java (Maven).

demande-ecosysteme.md Copier et remplir
Type de demande *
Langage de programmation / Écosystème
Nom du langage / écosystème *
ex. Python, Ruby, Java, Rust, .NET
Gestionnaire de paquets *
ex. pip / PyPI, Bundler / RubyGems, Gradle / Maven, Cargo, NuGet
Incluez l'outil (ex. pip) et le registre (ex. PyPI) si applicable.
Format du fichier de verrouillage *
ex. requirements.txt / Pipfile.lock, Gemfile.lock, pom.xml, Cargo.lock
CORAL analyse les fichiers de verrouillage pour résoudre l'arbre de dépendances complet.
Framework(s) de test utilisés dans cet écosystème *
ex. pytest, unittest / RSpec, Minitest / JUnit, TestNG / cargo test
CORAL génère des stubs de tests de conformité. Connaître le framework de test nous aide à produire un code idiomatique.
Cadres de conformité pour lesquels vous en avez besoin *
ex. RGPD, HIPAA, SOC 2 — je développe un service Python qui traite des données de santé
Pouvez-vous contribuer l'adaptateur d'écosystème ? (facultatif)
Oui / Non / Peut-être avec des indications
Les adaptateurs d'écosystème sont des modules autonomes. Si vous pouvez contribuer, un mainteneur vous expliquera l'interface.
